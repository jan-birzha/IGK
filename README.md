# ДОСПГФ — Инструмент формирования ПУД

Настольное приложение с графическим интерфейсом (Tkinter) для автоматизации подготовки пакетов учётных документов (ПУД): проставление номера ИГК на файлах, перенос списков имён файлов в шаблоны РДО (Excel), сопоставление данных ДЗО и конвертация Excel в XML.

## Возможности

- **Вставка ИГК в файлы** — добавляет текстовый штамп с префиксом «ИГК» в правый верхний угол (с учётом поворота страницы) PDF-файлов и в изображения (JPEG, PNG, TIFF, GIF), включая многостраничные/анимированные форматы.
- **Пакетная вставка ИГК** — рекурсивно обрабатывает все поддерживаемые файлы в папке и подпапках, с параллельной обработкой через пул потоков при большом количестве файлов.
- **Выбор папки для РДО** — собирает список имён файлов из директории и отображает их в таблице с возможностью перетаскивания (изменение порядка) и удаления строк.
- **Перенос списка в РДО (Excel)** — вставляет список файлов в целевой Excel-шаблон через COM-автоматизацию (`win32com`), с ручным вводом обязательных полей (дата, номер ГК, ИГК, лицевой счёт и т.д.).
- **Автозаполнение массива РДО** — то же самое, но пакетно для всех Excel-шаблонов в каталоге.
- **Работа с пакетом ДЗО** — отдельный рабочий процесс: сопоставление файлов со строками таблицы по имени, ручное редактирование и перенос данных в Excel.
- **Конвертация Excel → XML** — читает данные из Excel (начиная с 15-й строки) и формирует итоговый XML-файл на основе выбранного шаблона.
- Тёмный интерфейс в фиолетовых неоновых тонах, с адаптивными карточками-кнопками и таблицами.

## Структура проекта

```
.
├── main.py            # точка входа, запускает приложение
├── config.py           # константы, настройки UI-темы, параметры Excel/ИГК
├── utils.py            # общие вспомогательные функции (диалоги, профилирование, файлы)
├── igk_module.py        # логика вставки штампа ИГК в PDF/изображения
├── excel_module.py       # работа с Excel (РДО, ДЗО, конвертация в XML)
└── ui/
    ├── app.py           # главное окно и сборка интерфейса (IGKNameApp)
    └── widgets.py         # переиспользуемые виджеты (карточки, списки, таблицы)
```

> **Важно:** `main.py` и `app.py` импортируют модули из пакета `ui` (`from ui.app import IGKNameApp`, `from ui.widgets import ...`). Убедитесь, что `app.py` и `widgets.py` находятся в папке `ui/` рядом с файлом `__init__.py` (можно оставить пустым), а `main.py`, `config.py`, `utils.py`, `igk_module.py`, `excel_module.py` — в корне проекта.

## Требования

- **Python 3.10+** (используется синтаксис `X | None`, `from __future__ import annotations`)
- **Операционная система**: полный функционал (перенос данных в Excel через COM) работает только на **Windows** с установленным **Microsoft Excel**. Вставка ИГК в PDF/изображения работает кроссплатформенно (Windows/macOS/Linux).

### Python-зависимости

```
pymupdf
pypdf
Pillow
openpyxl
pywin32      # только Windows, для работы с Excel через COM
xlrd         # опционально, для чтения старого формата .xls
```

Установка:

```bash
pip install pymupdf pypdf Pillow openpyxl
pip install pywin32   # только на Windows
pip install xlrd      # опционально, если нужны файлы .xls
```

### Шрифт Arial

Для корректной отрисовки штампа ИГК приложение ищет системный шрифт Arial:
- Windows: `C:\Windows\Fonts\arial.ttf`
- macOS: `/Library/Fonts/Arial.ttf`
- Linux: пакет `msttcorefonts` или шрифт `Liberation Sans` (`/usr/share/fonts/truetype/liberation/LiberationSans-Regular.ttf`)

Если шрифт не найден, используется системный шрифт по умолчанию.

## Запуск

```bash
python main.py
```

После запуска откроется главное окно с боковым меню из трёх разделов:

1. **Работа с одним пакетом** — вставка ИГК в выбранные файлы, формирование списка файлов и перенос его в РДО.
2. **Работа с массивом пакетов** — пакетная обработка целых каталогов (ИГК и РДО).
3. **Работа с одним пакетом ДЗО** — отдельный процесс с таблицей сопоставления данных и конвертацией в XML.

### Типичный сценарий (один пакет)

1. Нажмите **«Вставка ИГК в файлы»**, выберите файлы, введите текст — он будет вставлен с префиксом «ИГК» в правый верхний угол каждого файла.
2. Нажмите **«Выбор папки для РДО»**, укажите папку — список имён файлов появится в таблице ниже (порядок можно менять перетаскиванием, лишние строки — удалить клавишей Delete или кнопкой).
3. Нажмите **«Перенести список в РДО (Excel)»**, выберите целевой Excel-файл — данные будут вставлены в шаблон, начиная со строки 15; при необходимости появится диалог для ручного ввода обязательных полей.

## Настройка

Все параметры (цвета интерфейса, шрифты, номера строк/столбцов Excel, поддерживаемые расширения файлов, число потоков для параллельной обработки и т.д.) вынесены в `config.py` — при необходимости адаптации под другой шаблон РДО правьте константы там.

## Известные ограничения

- Вставка штампа в подписанный электронной подписью PDF заблокирована намеренно (во избежание нарушения целостности подписи).
- Функции переноса данных в Excel через COM (`win32com`) требуют установленного Microsoft Excel и работают только в Windows.
- Профилирование времени выполнения отключено по умолчанию (`ENABLE_PROFILING = False` в `config.py`).
